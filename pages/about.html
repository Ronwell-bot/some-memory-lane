SOME MEMORY LANE

About Some Memory Lane

A simple browser-based photobooth designed to turn everyday moments into memories worth keeping.

The Project

Memory Lane is a personal portfolio project created by Ronwell Carcer. It is designed to feel like a simple, warm photobooth experience in the browser.

The Idea

The goal is to help people create printable memories without complicated setup. The project takes inspiration from classic photo booths, scrapbook keepsakes, and everyday moments.

Still Growing

Memory Lane is still a growing project. New features, themes, layouts, and improvements may be added over time.
